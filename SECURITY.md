# Security Policy

## Reporting a vulnerability

Please **don't** open a public issue or pull request for a security problem.

Report it privately instead:
**Security** tab → **Report a vulnerability**
(https://github.com/HiBiz-AI-SERVICES/hibiz-docs/security/advisories/new)

Please include:
- what is affected (page, file or link)
- how to reproduce it
- the impact you expect

We acknowledge reports within 2 business days and keep you updated until it is fixed.

## Scope

This repository holds public documentation. Reports about HiBiz services are welcome through the same channel.
